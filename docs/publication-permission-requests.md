## サイトの説明

- サイト名: はまむび！
- 検証版URL: https://yokohama-cinema-schedule.pages.dev
- 目的: 横浜周辺の複数映画館について、その日に観られる作品と上映時刻をスマートフォン向けの番組表形式で探しやすくする
- 運営形態: 個人運営、当面は非営利・広告なし
- 掲載予定の情報: 映画館名、作品名、上映日、開始・終了時刻、スクリーン、上映形式、公式予約ページへのリンク
- 掲載しない情報: 座席残数、料金、作品のあらすじ、公式ページ本文の転載
- 作品画像: 権利者と利用条件を別途確認できない限り、一般公開版では表示しない
- 取得範囲: 当日から最大7日分
- 検証中の更新頻度: 約3時間ごと、1日7回。公開時には1日1〜2回など、指定された頻度へ変更可能
- 訂正・停止: 誤りの連絡や掲載停止の要望を受けた場合は速やかに修正または停止する

## 共通して確認する項目

回答が曖昧にならないよう、次の項目を分けて質問します。

1. 上映スケジュールの事実情報を、見やすく再構成して一般公開すること
2. 公式サイトまたは公式サイトが表示に利用するデータを、定期処理で自動取得すること
3. 映画館名を表示し、公式劇場ページ・予約ページへリンクすること
4. 許容される更新頻度、出典表記、免責表示、削除対応などの条件
5. 作品画像は今回の許諾対象外とし、別途許諾できる場合のみ条件を確認すること

## 回答の記録項目

回答を受け取ったら、映画館ごとに次を記録します。

| 項目 | 記録内容 |
|---|---|
| 回答日 | `YYYY-MM-DD` |
| 回答者 | 会社名、部署、氏名または窓口名 |
| スケジュール掲載 | 許可 / 条件付き許可 / 不許可 |
| 自動取得 | 許可 / 条件付き許可 / 不許可 |
| 取得頻度 | 指定された上限 |
| リンク・名称表示 | 表記方法とリンク先 |
| 画像 | 許可範囲。回答がなければ公開しない |
| 必須表示 | 出典、免責、更新時刻など |
| 有効期間 | 期限、更新確認日 |
| 証跡 | メールまたは問い合わせ受付番号の保管場所 |

許諾を得た映画館のみ`approval = 'approved'`とし、条件を満たせない映画館は`private_only`または`disabled`のままにします。
